### Performance
- Cached entity field offsets, team and game-rules lookups: bot think time with 22 bots went from about 9.8 to 2.8 ms per frame in a test run. `ffnb_perf [reset]` profiles server frames.

### New
- Optional `ff_civilian_anywhere` SourceMod plugin: allows the Civilian on every map except excluded ones (Hunted and ff_training by default) by changing only the Civilian class limit, so map scripts stay stock.
