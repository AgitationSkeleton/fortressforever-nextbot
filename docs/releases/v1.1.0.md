### New behaviour
- **Security switches** (`base_shutdown` maps: ff_destroy, ff_schtop, ...): attackers turn off the enemy's security before going for a flag behind it. Lasers and slayers are avoided according to their Lua team filter.
- **Demomen** plant detpacks on the map's detpack targets (`ff_bot_detpack`); **pyros** use the jetpack (`ff_bot_jetpack`); **scouts** build and ride jump pads where a simulated launch pays off (`ff_bot_jumppad`); **spies** sabotage sentries and dispensers the FF way.
- **Grenades** are chosen per situation from both slots (MIRV against groups and buildings, EMP against buildings and ammo-heavy classes, napalm against groups, conc up close); `ffnb_grenades` counts throws.
- **Team balance** across all four teams (`ff_bot_auto_balance`); a map without a nav mesh is announced in chat.

### Nav
- Nav meshes for 60 maps (attached to this release).
- Nav generation passes door models parented to func_doors.

### Notes
- Some community map scripts fail to load because FF 2.0 doesn't define `trigger_detpackable_door` (ff_cornfield, ff_ksour, ff_napoli, ff_avanti_classic). See the README's Known gaps for the one-line fix.
